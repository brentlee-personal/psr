# 结果读取边界

`Query` 单次调用已有连接、连接池或事务的 `QueryContext`，传入调用者提供的上下文与参数，零重试，不解析语句、不选择数据源、不打开 DSN，也不建立身份或授权。`Read` 接管 `sql.Rows.Close`；连接和事务仍归调用者。严格入口要求正行数及字节上限；无效配置在发查询前拒绝，已交给 `Read` 的 Rows 仍被关闭。

结果使用有序列与二维值数组，保留重复列、整数、字节和完整时间，复制驱动可能复用的字节缓冲。列带驱动可提供的数据库类型名；驱动未报告则留空。NaN、Inf、非标准驱动值及不可编码时间返回安全类别，既不改成 null，也不把原始驱动错误、SQL 或值写入错误和日志。

完整性零值为未知。仅单结果集读到 EOF、迭代无错、Rows 关闭确认且最后上下文仍有效，才返回读取完整。恰好 N 行继续读取一次以确认 EOF；第 N+1 行证明超限。无数据仍必须有列。字节超限、扫描错误、Rows.Err、额外结果集及关闭失败不构成完整成功。因 EOF 自动关闭的错误可能由 database/sql 通过 Rows.Err 报告，因此错误类别为迭代失败，关闭状态仍为未知。

`RetainedBytes` 精确计算 encoding/json 编码的 `{"columns": [...], "rows": [...]}` 载荷大小，包含列元数据、JSON 结构、字符串转义和字节的 base64 编码，不包含完整响应的其他字段。新增行若导致超限不保留，该字段保持上一份已保留载荷大小。最终响应封装者仍需重新核算完整响应上限。本实现会为候选载荷编码；database/sql 或驱动也可能先为巨型单元格分配内存，因此 1 MiB 保留结果检查不能证明网络或进程内存硬上限，提供者仍需独立限制。

取消与截止在发查询前和元数据、Next、Scan、Close 等阶段后重查。调用者须传入请求、查询、身份、授权、批准句柄期限中的最早截止；本层不产生或延长截止。驱动忽略取消时同步等待实际返回；没有把工作移入后台的超时出口。最终检查仍有普通并发的边界：返回后发生的撤权或取消必须由响应释放方检查。

`RowsClose` 只表示 Rows 关闭阶段观察成功，不表示数据库查询已停止，也不证明事务回滚、连接隔离或完整清理。本层不提供 DB 停止、容量释放或自动重试许可。只有驱动失败而没有拿到 Rows 时，关闭状态保持未知。

现有 ExeSQL 通过专用 `QueryLegacy` 使用同一个读取循环。该入口只服务当前工具外层合同：保留原始驱动错误、无字节限制、忽略提前 Close 错误，不宣称完整性；日期、字节、NaN/Inf 表现、重复列覆盖、无记录提示及多语句错误内嵌仍归旧工具外层。受限执行必须调用严格 `Query`，不可注册为模型工具或把结果交回 Canvas、聊天、模型回调、原始追踪和日志。

本次合成驱动测试只验证读取阶段：N−1/N/N+1、空结果及空列拒绝、重复列、缓冲复用、时间与整数、非法值、JSON 字节边界、查询/扫描/迭代/关闭失败、取消/截止及忽略取消时同步等待；现有工具的窄回归另外验证外层合同。

完整公开 Executor、不可伪造 ApprovedQuery、当前授权重核、全局 SourceRef 受控解析、实际只读协议与身份、数据库终态观察、事务/连接收尾、跨进程并发容量和持久恢复记录尚未交付。下一阶段由共同执行器及数据面负责人提供这些接口与实际驱动证据；未知清理必须持久锁存，不可因本地 RowsClose 确认释放容量。真实业务、实际驱动协议、恢复观测、企业版与成员 ACK 均为 NOT_RUN。
