# RAGFlow to PSR contract gaps

Assessment source is center commit `63ec3bc56d463bc5053c357b743ceedffee485ca`, based on the BRE-200 merge. This is a source review and fixture experiment. No live RAGFlow service, PSR verified store, compiled artifact, or production tenant boundary was exercised.

| Contract | Native evidence | Gap and sidecar treatment |
| --- | --- | --- |
| Stable source identity | Dataset and document primary keys exist in `api/db/db_models.py:1265,1324`. Upload keeps connector IDs or generates a UUID in `api/db/services/file_service.py:609`. | Preserve instance, tenant, project, dataset, document, and chunk IDs. A name is not an identity. This does not establish stability across upstream delete and recreate. |
| Content revision | `chunk_api.py:1274` derives an add-time chunk hash, but `chunk_api.py:1426-1436,1510` edits the existing ID. `db_models.py:1344` permits an empty xxhash128 document fingerprint. `file_service.py:627-638` also accepts connector fingerprints. | An ID or update timestamp is not an immutable PSR revision. The sidecar hashes exact exported chunk text and retains immutable observed generations. Upstream fingerprints remain opaque. |
| Anchors | `api/apps/restful_apis/chunk_api.py:683-694` exports IDs and optional positions. `chunk_api.py:156-162` checks five-element tuples. Keyword queries can return highlighted normalized content at `chunk_api.py:684`. | Positions do not establish stable source lines across reparsing. The sidecar binds native chunk positions to a content observation. Trusted external provenance supplies GitHub commit and line anchors for the frozen corpus. It never derives line numbers from parser positions. Acquisition omits keyword filtering. |
| Whole source versus excerpt hash | Frozen BAS corpus hashes refer to whole files, per its eval README. RAGFlow exports chunk text. | Evidence hashes exact exported chunk bytes. The adapter view separately retains the original whole-file hash. These digests have different scopes. |
| Incremental discovery | `document_api.py:896-899` accepts update-time ordering. `document_service.py:135-178` joins file tables and uses offset pagination without a transaction snapshot or stable tie-breaker. | A listing cannot promise CDC completeness. This demo accepts explicitly complete authorized fixture snapshots, validates counts and scope, and diffs them. It does not poll a live service or infer physical deletion from an arbitrary missing list row. |
| Deletion propagation | `document_api.py:1182-1209` checks membership before deletion. `document_service.py:468,516-543` removes DB state and catches some index or derived-product cleanup failures. `document_service.py:551-602` contains graph and reference-counted wiki cleanup. | Native cleanup exists. Its response does not establish an atomic external PSR invalidation feed. The overlay withdraws current references only for a complete scoped snapshot. Deleted sources retain private audit data and deny ordinary history reads. |
| Native knowledge compilation | `api/apps/services/dataset_api_service.py:2298-2347` compares active chunk hashes with a MAP snapshot, including same-ID changes, and computes changed document IDs. ACL is checked at `dataset_api_service.py:2541-2544`. `chunk_api.py:631-638,719-720` excludes compiled rows from source chunk reads. | Native compilation has freshness detection. Compiled products are not PSR verified assertions or an admission decision. This adapter imports source chunks only. A compiled-artifact adapter and real compilation replay remain unimplemented. |
| ACL | `knowledgebase_service.py:577-591` allows owner access or team membership in the owning tenant. `chunk_api.py:707-720` also binds a chunk to its document. API auth supplies the requesting user ID under the name tenant_id at `api/utils/api_utils.py:239-247`. | Native me/team ACL is not the PSR principal role model. Trusted sidecar metadata supplies the fixture readers and owning scope. All read methods require the current scope and ACL, including historical records and ChangeSets. This is not a live membership synchronization or authentication implementation. |
| Lifecycle and governance | BAS `change-set.schema.json` supports propose and transition. Its runtime `tests/semantic-runtime/m0/context.cjs:90-113` forbids duplicate proposals and permission mutation during transitions, and protects verified GitHub deprecation. | Emit proposed records and overlay deprecations only. ACL changes affect the private current-source gate. The sidecar neither applies ChangeSets to BAS nor writes verified facts. Schema validity is not governance authorization or complete graph acceptance. |
| Unknown and answer quality | The frozen `rag_baseline/retriever.cjs` ranks excerpts. Its README states that retrieval hits do not supply fact accuracy. | Both comparison systems return evidence plus an explicit unknown answer. Known-case abstentions remain visible. No semantic answer generator, complete dependency graph, external inventory, crawler probe, or live provider probe exists here. Owner adjudication and M3 accuracy remain pending. |
